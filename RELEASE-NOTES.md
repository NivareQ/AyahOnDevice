# AyahOnDevice v2.0

AyahOnDevice v2.0 is a major update focused on stronger local identification, bilingual usability, personal continuity, and offline reliability.

## User-facing changes
- complete English/বাংলা interface localization with independent Quran-translation selection;
- Exact Match Context for deterministic Arabic phrase occurrence discovery;
- Confirm & Learn for fully local, bounded result re-ranking, with Undo and reset controls;
- expanded History integration for confirmations and corrections;
- curated familiar/context labels for 15 selected ayat/passages, in English and Bengali;
- Personal Backup v2 covering Saved items, History, learned recognition, and portable preferences;
- stronger IndexedDB migration, restore validation, atomic restore behavior, and reset recovery;
- improved offline/PWA cache handling and cold-start language/theme behavior.

Quran text remains sourced from the bundled canonical Quran data. Local AI output is used only as search input and never replaces displayed Quran text.
