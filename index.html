Guide

Simple ways to get good results.

1. Recite a short fragment

About 4–12 seconds is ideal. You do not need to remember the whole ayah.

2. Imperfect recognition is okay

The words under “What local AI heard” are only a search clue. They do not need to be perfect for AyahOnDevice to find the right verse.

3. Compare close results

Similarity scores help rank possible matches; they are not probabilities. If several results look plausible, compare them before opening one.

4. Offline use

Open the app once online and allow offline voice recognition to finish preparing. Then use Settings → Check offline availability to confirm that voice recognition and the Quran reader are ready without Internet access.

5. Advanced local models

On a powerful computer, Settings → Offline voice recognition can optionally load a compatible larger local model file from the device.

6. Saved titles & notes

Saving stays one tap. Open Saved later if you want to add an optional title or note, then use Saved search to find it again.

7. Backup

Settings → Personal data can download or restore Saved items, titles/notes, History, learned recognition, and reader preferences. Backup files are plain JSON, so keep them private if your History or notes are personal.

8. Opening Bismillah

The opening Bismillah alone is not used to identify a passage because it does not uniquely locate an ayah. Recite a little more and AyahOnDevice will match the words that follow.

9. Confirm & learn

Use ✓ Correct when a displayed interpretation is the one you meant. AyahOnDevice learns only a local re-ranking preference for similar future searches; it never changes Quran text or the original similarity score. Use Undo immediately or Settings → Recognition learning to reset all learned preferences.

10. Quran text integrity

Voice recognition is used only to identify possible matches. Quran text shown by AyahOnDevice comes from the local Quran data, not from generated speech-recognition text.

About

AyahOnDevice
A NivareQ™ project

AyahOnDevice helps identify Quran verses from a remembered spoken or typed fragment and includes a full local Quran reader.

Privacy

Voice recognition runs on this device. Audio is not sent to a cloud speech service for transcription. A recognized transcript is used only as a search clue. Search History and learned recognition preferences stay on this device.

Quran text integrity

Recognized speech never becomes displayed Quran text. Quran text shown by AyahOnDevice comes from the included Quran data.

Quran & translation sources

Quran source data: Tanzil Uthmani, with the routine opening Bismillah presented separately from the first numbered ayah where applicable. IndoPak display text and its dedicated font come from DigitalKhatt resources. Translations: QuranEnc sources where noted, plus public-domain Pickthall and Yusuf Ali. Full source and version details are included with the app.

Offline voice recognition

The default local voice model is verified before use and can be stored on this device for offline recognition. Compatible larger local model files can optionally be selected from Settings on capable computers.
